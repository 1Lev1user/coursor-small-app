# Story map

Order of work: product goal, actors, backbone, steps, slices, then cards.

1. Product goal and constraints: confirm in SPEC.md (use the grill skill if unclear).
2. Actors: who uses or is affected. Include the owner and operators, not only end users.
3. Backbone: the activities each actor performs, in time order, left to right. Fill the table in STORYMAP.md: Actor, Activity, Value for whom.
4. Steps: under each activity list the concrete steps, most important first. Give each an ID (S1.1) and a priority.
5. Slices: cut horizontally. Slice 1 is a thin first slice: the smallest set of steps that works end to end and delivers value to one actor. Later slices add depth.
6. Gaps and creep: every step needs at least one card; every card needs a step.
7. Ask the user to approve the map before cards are written.

Do not build features that are not on the map. A new idea goes to the map first, then to a card.
