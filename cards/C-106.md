## Goal
The README and the user guide list the banks and formats 3.1 reads. Each is marked "checked with a real export" (Citadele .xls) or "built from public descriptions" (the rest), so people know what to report. They also explain:
- how to map columns by hand for banks not on the list (Luminor, Citadele CSV, Paysera);
- the new behaviours: skipped pending rows, fees, transfers between own accounts, reversals and batches.
