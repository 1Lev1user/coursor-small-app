## Goal
Direct tests for escapeField edge cases.

## Acceptance
- `node --test test/csvQuoting.test.js` exits 0
- `node --test test/csvQuoting.test.js 2>&1 | grep -E '^# pass ([4-9]|[1-9][0-9])'` exits 0

## Do not touch
- src/
- existing test files

## Notes
Existing test/csv.test.js lines 73-100 already cover doubled quotes, embedded newline and the delimiter for both flavours through buildMonthCsv, and line 191 covers formula escaping, so those are out of scope. Cover only escapeField(value, delimiter) called directly (src/csv.js, verified: quotes when the text contains the delimiter, a double quote, \n or \r; doubles quotes; no special handling of leading/trailing spaces): (1) a value containing \r is quoted; (2) a value containing the delimiter is quoted, for ',' and for ';' (two tests or one test with both); (3) a value with no special characters is returned unchanged; (4) a value with leading/trailing spaces and no special characters is returned unchanged (spaces are not special). At least 4 passing tests. Allowed path is the new test file only.
