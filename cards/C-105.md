## Goal
"Undo this import" removes every entry of the import, also those the person corrected afterwards (new category, amount, note), without saying so (research/3.0/C2-power-user.md 1.11). After this card, entries changed after the import carry an "edited" mark. Undo then shows "3 of 42 entries were changed after the import" and asks: remove all, or keep the changed ones. Nothing else about undo changes.

## Notes
- `undoImport(data, importId, now, { keepEdited })` (core.js ~724) removes only unedited entries when `keepEdited` is true. A new `importEditInfo(data, importId)` returns `{ total, edited }`.
- Both undo buttons show the counts and two choices when edited > 0: "Remove all" and "Keep the 3 changed". The buttons are importSettings.js:146 and the one after an import (import.js ~1750). When edited is 0, today's flow is unchanged.
- Tests: editedAt is set only on a real change; undo with keepEdited keeps exactly the edited entries; undo without it removes all (today's behaviour); importEditInfo counts; normaliseEntry keeps editedAt and defaults it to ''.
