Tests with fixed NOW: 60 days + snoozed -> overdue; 59 days + snoozed -> null; 90 days, not snoozed -> overdue; never + snoozed -> null. 'Scheduled' export without a tap is not possible in a browser; this is the agreed substitute (decision D3).
