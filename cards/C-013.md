- `npm test` exits 0

## Notes
Owner decisions 2026-10-03: the guide becomes a Word document (C-014) and the screenshots are retaken. scripts/capture_guide_screens.js uses Playwright (`import { chromium } from 'playwright'`), which is not installed and not a project dependency. Running it needs the owner's approval to install Playwright and its Chromium browser (about 150 MB) on this machine, outside package.json (for example `npx playwright@<version> install chromium` plus a temporary install). Do not add Playwright to package.json. Update the sample data if a screen needs it (for example a pre-update copy for the Restore button, an old lastBackupISO for the overdue reminder) and add Trends and Import to the list if missing. Keep the existing file names so links stay valid; add new files only for new screens. Install photos (android-*, iphone-*) are not retaken.
