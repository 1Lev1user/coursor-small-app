Add const NO_UNZIP = 'This browser cannot open Excel files. Save the file as CSV and try again.'; in inflateRaw throw a NoUnzipError (pattern: TooLargeError) when typeof globalThis.DecompressionStream !== 'function'; map it to NO_UNZIP in the catch. Stored (method 0) entries keep working. Tests: copy the small ZIP writer from the top of test/importXlsx.test.js; build the deflated workbook BEFORE removing the global (the writer uses CompressionStream); delete globalThis.DecompressionStream in try/finally and restore it. (1) deflated workbook -> ok false, reason NO_UNZIP; (2) stored workbook -> ok true with rows.
