## Goal
Three fixes from the C-089 review (PR #82) so that the details split never loses text from other banks' files and never keeps a card number in a transfer's text:
1. Text after the payee line is kept. Today a cell such as "PARAUGS SIA LV00HABA0000000000001" + newline + "Rēķins par decembri" loses its second line, because everything after the party line is dropped.
2. Only a real IBAN makes a party line. Today any token shaped like two letters, two digits and 11-30 letters or digits counts, so "Invoice PR2026123456789" + newline + "second line" becomes payee "Invoice" with an empty text.
3. Card masks (`400000******0000`) are removed from a transfer's purpose lines, like IBANs and personal codes.

## Notes
Code at 0bd76c3 (src/import/details.js):
- `IBAN_SOURCE` (line 1) is `[A-Z]{2}\d{2}[A-Z0-9]{11,30}`. Make a token count as an IBAN only when its first two letters are an IBAN country code and its length matches that country's IBAN length (ISO 13616 registry). At least these countries: LV 21, EE 20, LT 20, FI 18, SE 24, DE 22, PL 28, GB 22, IE 22, NL 18, BE 16, FR 27, ES 24, IT 27, AT 20, DK 18, NO 15, CH 21, LU 20, CZ 24, SK 24, PT 25, MT 31, CY 28, GR 27, HU 28, RO 24, BG 22, HR 21, SI 19. Do NOT check the mod-97 checksum: the made-up IBANs in test/importDetails.test.js (LV00...) have invalid check digits on purpose and must keep working. Apply the same rule to the BIC lookahead (line 16) and to `IBAN_ALL` scrubbing (only real-length IBANs are removed).
- `splitTransfer` (~57-80): the description is the lines above the party line. Make it those lines plus the lines after the party line, except the `Maksātāja reference:` line, with IBANs, personal codes and card masks (`\d{4,6}\*+\d{4}`) removed, joined with a space.
- Tests (new file, made-up data):
  1. A party line followed by a purpose line → the purpose is the description.
  2. A purpose before the party line and more text after it → both are kept, in order.
  3. "Invoice PR2026123456789" + newline + "second line" → unchanged (counterparty '', description = the collapsed text).
  4. An IBAN of a listed country with the wrong length → not a party line.
  5. A card mask in a purpose line → removed from the description.
  6. The three Citadele transfer shapes of test/importDetails.test.js still give the same counterparty and description (repeat one of them).
