## Goal
C-089 reads the payment date and merchant from Citadele card lines. Swedbank and SEB write card payments differently (research/3.1/bank-shapes.md, READ):
- Swedbank LV memo: `PIRKUMS <masked card> <yyyy.mm.dd> <hh.mm> <amount> <CCY> (<auth>) <merchant>`. Foreign purchases add `VALŪTAS KURSS …` and `KONVERTĀCIJAS MAKSA …`.
- SEB: the purpose text carries `DD/MM/YYYY HH:MM`. A foreign purchase reads like `299.00 NOK(25.67 EUR + mokestis 0.68 EUR(2.65%))`.

After this card these shapes give the merchant as the payee and the card date as the entry date (same 0-60 day window as C-089). The card number is removed from the text. For a foreign purchase, the original amount and currency are recognised and offered as the original amount.

## Notes
- Add new shapes in `splitBankDetails` next to the Citadele card shape. The order is: Citadele shape first, Swedbank, SEB, then transfer, then the fallback. The existing Citadele and transfer results must stay identical (their test files stay green).
- Swedbank: `^PIRKUMS\s+\d{4,6}\*+\d{4}\s+(\d{4})\.(\d{2})\.(\d{2})\s+\d{2}[.:]\d{2}\s+([\d.,]+)\s+([A-Z]{3})\s+\(\w+\)\s+(.+)$`. The merchant is the last group, with the `VALŪTAS KURSS`/`KONVERTĀCIJAS MAKSA` tail removed.
- SEB: the date `DD/MM/YYYY HH:MM` inside the purpose. The original amount comes from `(\d+[.,]\d{2}) ([A-Z]{3})\((\d+[.,]\d{2}) EUR`.
- Return an extra `original: { cents, currency }` only when found. The caller ignores it until a later card wires it in, unless it can be passed without touching other files.
