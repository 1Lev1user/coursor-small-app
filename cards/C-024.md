## Goal

## Do not touch

## Notes
Decision F3: keep noindex. The test asserts that index.html contains <meta name="robots" content="noindex, nofollow"> (index.html:11). A project site at 1lev1user.github.io/coursor-small-app/ cannot use its own robots.txt (crawlers read it only from the host root), so the meta tag is the only control. The PDF in docs/ on v1 cannot carry it (see C-025).
