## Goal
Short motion that answers the owner's actions (owner decision 29, quiet part): the toast slides in and out every time (also when a second toast replaces the first), the entry just added is briefly highlighted where it landed, and a deleted row collapses before it disappears. Under Reduce Motion only colour and opacity change, with no movement.

## Acceptance
- `node --test test/quietMotion.test.js` exits 0
- `npm test` exits 0
- Manual (design-review): Month after adding an entry and after deleting one, toast shown twice in a row, at 390 px, light and dark
- Manual (owner): on the iPhone: add two expenses quickly, each toast slides in; delete an entry in Month, the row folds away and the Undo toast appears; with Reduce Motion on, nothing slides

## Notes
Source: research/3.0/design-apple.md section 4 items 2, 7, 8; design-impeccable.md section 4 items 4, 5. Tokens: reuse `--ease` (:121); add `--ease-in: cubic-bezier(0.4, 0, 1, 1);`. Only `transform` and `opacity` move, except the row collapse, which uses `grid-template-rows`. Line numbers from main at 6788db8; verify.

1. Toast. Replace the `toast-in` keyframe (:929, :950-955) with a class transition: `.toast` starts `opacity: 0; transform: translate(-50%, 8px)`; `.toast.is-shown` is `opacity: 1; transform: translate(-50%, 0)`; enter 200 ms `var(--ease)`, exit 150 ms `var(--ease-in)`. `toast()` adds `is-shown` on the next frame; to hide, remove `is-shown` and remove the node on `transitionend` (with a 300 ms fallback timer). A second toast while one is shown: hide-and-show again so the enter motion replays. Reduced motion: opacity only, 120 ms.
2. New row highlight. After a save, the saved entry's id is passed to the next render (e.g. a module-level `highlightId` in app.js read once by the Month and Home lists, then cleared). The matching row gets class `is-new`: `background-color` from `var(--block-soft)` to transparent over 900 ms after a 150 ms hold. This is colour, so it stays under reduced motion (shorter, 400 ms).
3. Row removal. On delete confirm in Month: wrap the row content in a grid with `grid-template-rows: 1fr`, animate to `0fr` with `opacity` to 0 over 200 ms `var(--ease)` (Web Animations API `row.animate(...)`), then run the existing delete and `render()`. Reduced motion: no animation, delete at once. The Undo toast stays.
4. Helper in src/motion.js (from C-075): `export function afterMotion(animation, fallbackMs)` returning a Promise that resolves on `finish` or after `fallbackMs`, so a lost event never blocks the delete.
5. Tests `test/quietMotion.test.js`: style.css has `.toast.is-shown`, no `@keyframes toast-in`, `.is-new` uses a background colour transition, and every new `transform` transition sits inside `@media (prefers-reduced-motion: no-preference)`; `afterMotion` resolves on a fake animation's `finish` and on the fallback timer (use `node:test` mock timers).
