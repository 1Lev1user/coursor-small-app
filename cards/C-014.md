## Goal
The user guide describes version 3.0 and is built the same way as the 2.0 guide: `scripts/build_user_guide_pdf.py` (reportlab, already installed on this machine) writes the PDF to docs/ (git-ignored) and copies it to the owner's Desktop.

## Acceptance
- `python scripts/build_user_guide_pdf.py` exits 0 and prints the page count
- `test -f docs/My-Expenses-User-Guide.pdf` exits 0
- `git check-ignore -q docs/My-Expenses-User-Guide.pdf` exits 0
- `npm test` exits 0
- Manual (owner): open the PDF from the Desktop: sections Getting started and the 3.0 money setup, Money now and the per-day amount, Paydays and regular incomes, Check against the bank, Adding entries (refund, quick add), Month, Chart and Trends, Settings (groups), Import a bank statement (check panel, duplicates, reverse direction), Backup and restore (preview, safety copy, pre-update copy), Install on phone; screenshots from docs/guide-assets/ (C-013); plain language, no real personal data

## Do not touch
- src/
- docs/guide-assets/ (C-013 owns the screenshots)
- existing test files
- .gitignore (C-025 already ignores the PDF)
- Limit for `scripts/build_user_guide_pdf.py`: the guide text, the section list and the screenshot names; keep the output paths, the page setup, the fonts and the footer.
