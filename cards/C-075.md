The one deliberate motion moment (owner decision 29): when the owner returns to Home after saving, editing or deleting an entry, the "Money now" amount rolls from the old to the new value and the month budget bar grows or shrinks to its new length, about 600 ms. Nothing moves under Reduce Motion.

## Notes
Source: research/3.0/design-frontend.md section 4 ("Spend lands") and design-impeccable.md section 4 item 3; owner's choice: decision 29 "main + quiet". This card starts after C-039, which builds the new Home (Money now first, then the per-day amount, then the month budget). Read C-039's merged code first.

1. New module `src/motion.js`:
   ```js
   export const prefersReducedMotion = () =>
       typeof matchMedia === 'function' && matchMedia('(prefers-reduced-motion: reduce)').matches;

   export const easeOutCubic = (t) => 1 - (1 - t) ** 3;

   // Value at time `elapsed` of a tween from `from` to `to` cents; integers only.
   export function tweenValue(from, to, elapsed, duration) {
       if (elapsed >= duration) return to;
       return Math.round(from + (to - from) * easeOutCubic(Math.max(0, elapsed) / duration));
   }

   // Runs onFrame(cents) on each animation frame, ends exactly on `to`.
   export function rollNumber({ from, to, duration = 600, onFrame, raf = requestAnimationFrame, now = () => performance.now() }) {
       if (from === to || prefersReducedMotion()) { onFrame(to); return; }
       const start = now();
       const step = () => {
           const value = tweenValue(from, to, now() - start, duration);
           onFrame(value);
           if (value !== to) raf(step);
       };
       raf(step);
   }
   ```
2. Last shown value: a module-level `let lastMoneyNowCents = null;` in add.js. On Home render: if it is `null` (first render since app start) show the value without motion; if it differs, roll from it; then store the new value. A tab switch with no change does nothing.
3. Accessibility: the rolling text sits in a span with `aria-hidden="true"`; a visually hidden sibling holds the final formatted value for screen readers (use the existing visually-hidden class if style.css has one; search `sr-only` or `visually-hidden`).
4. Budget bar: the fill gets `transform-origin: left; transition: transform 600ms var(--ease);` inside `@media (prefers-reduced-motion: no-preference)`. Render it at the old scale (`transform: scaleX(old)`), then on the next frame set the new scale. Width stays the honest final value in CSS; only `transform` moves (compositor only, no layout).
5. Tests `test/motion.test.js`: `tweenValue(1000, 4000, 0, 600) === 1000`; `tweenValue(1000, 4000, 600, 600) === 4000`; values are integers and never pass `to` for both rising and falling tweens; `rollNumber` with a fake `raf` and fake `now` calls `onFrame` last with exactly `to`; with `from === to` it calls `onFrame` once.
