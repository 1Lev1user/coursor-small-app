## Goal
Move the built PDF guide out of the repository tree.

## Acceptance
- `test ! -e docs/My-Expenses-User-Guide.pdf` exits 0
- `grep -c 'My-Expenses-User-Guide.pdf' .gitignore` prints 1 or more
- `du -sk docs | awk '{exit !($1 < 1300)}'` exits 0
- `npm test` exits 0
- Manual (owner, before merge): create a GitHub Release with the PDF (gh release create or the web UI); the README link opens it

## Do not touch
- history rewrite (filter-repo, BFG)
- force push
- docs/guide-assets/
- branch v1
- Limit for `docs/My-Expenses-User-Guide.pdf`: delete.
- Limit for `README.md`: one link line.
- Limit for `scripts/ship-files.txt`: only if C-005 is done.

## Notes
Decision F4: the PDF leaves the repository and is published as a GitHub Release asset; guide-assets stay. Measured: docs/ is 2.3 MB (PDF 1.2 MB; 13 PNG 1.1 MB, of which 4 install photos 720 KB). docs/ blobs total 13.5 MB across history (git rev-list --objects --all -- docs). Removing the file from the tree does not shrink clones; only a history rewrite would, which is irreversible and excluded. The builder still writes to docs/ (build_user_guide_pdf.py:28); .gitignore keeps that output untracked. Nothing in src/, index.html or README links the PDF today (grep). v1 carries docs/ today; the next publish follows ship-files.txt.
