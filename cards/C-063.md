## Goal
An .xlsx bank export with a "Summary" first sheet, or with a hidden first sheet, imports the transactions sheet instead of a dead end. Today only the first `<sheet>` of the workbook is read; the Columns step then cannot succeed ("Choose the date column", 0 rows imported) and nothing says other sheets exist.

## Notes
Source: D-bank.md problem 9 (VERIFIED, probe p06_xlsx.mjs X2, X3), independently confirmed in D-bank-verify.md item 6 (probe c6.mjs: `readXlsx` returns ok:true with the 3 summary rows, wizard headerRow -1, 0 imported; control with the transactions as sheet 1 gives 6 rows). Whether any real bank exports a multi-sheet workbook is UNVERIFIED.

Cause: `firstSheetPath` (src/import/xlsx.js:140-150) takes the first `<sheet>` of xl/workbook.xml; `readXlsx` (:380-433) reads only that path (:412-413).

Fix outline: list all `<sheet>` elements with their relationship target and `state` attribute (`hidden` and `veryHidden` are not visible). Read the visible sheets in workbook order (cap at the first 10), build rows with the existing `readRows`, and pick the first sheet that has at least 3 rows and at least one cell that looks like a date (`YYYY-MM-DD` from a date-styled cell, or a text date such as `13.09.2026` or `2026-09-13`). If none qualifies, fall back to the first visible sheet, then to the first sheet, so single-sheet workbooks behave exactly as today. Shared strings and styles are read once.

Regression tests (new file; copy the small ZIP writer and workbook helpers from the top of test/importXlsx.test.js, which also shows the `<sheets>` and rels shape):
1. The failing input from the research: sheet 1 "Summary" with rows `Konts | LV00TEST`, `Periods | 01.09.2026 - 30.09.2026`, `Atlikums | 987,50`; sheet 2 "Transactions" with header `Datums | Apraksts | Summa` and 5 rows with dates like `13.09.2026`. EXPECTED: rows are the 6 transaction-sheet rows. ACTUAL before: the 3 summary rows.
2. Hidden first sheet (`state="hidden"`) holding transaction-looking rows, visible second sheet holds the real ones: the visible sheet is read.
3. Control: transactions as sheet 1 and a Summary as sheet 2: sheet 1 is read (6 rows).
4. No sheet qualifies (one sheet with 2 text rows): the first visible sheet is returned unchanged.
5. A single-sheet workbook built like in importXlsx.test.js returns exactly what it returned before.
