## Goal
Several internet banks save statements as ".xls" files that are in fact an HTML table, or an Excel 2003 XML workbook ("SpreadsheetML"). Today both get "This file does not look like a bank statement" (research/3.0/D-bank.md section 15, VERIFIED). After this card both are read as tables, like CSV and Excel, and continue to the Columns step.

## Notes
Amendment 2026-10-17 (card-planner check): test/importDetect.test.js:66 asserts that `<html><body>Hi</body></html>` is 'unknown'. So 'html' also requires `<table` and `<tr` somewhere in the text, and a page without a table stays 'unknown'. `decodeEntities` (xml.js) does not know `&nbsp;`, so htmlTable.js needs a small named-entity map. No fixture files: the samples are inline strings in the test.

- Detection, after decodeBytes:
  - text starting (after whitespace or a BOM) with `<html`, `<!DOCTYPE html` or `<table`, or containing `<table` within the first 4 KB → 'html';
  - an XML root `Workbook` with namespace `urn:schemas-microsoft-com:office:spreadsheet` → 'spreadsheetml'.
- `htmlTable.js` exports `readHtmlTable(text)` → `{ ok, rows }`. It picks the table with the most rows that has a date-like cell. It reads <tr> with <td>/<th>, decodes entities (reuse `decodeEntities` from xml.js), turns <br> into line breaks, strips other tags, and expands colspan with empty cells.
  - No DOMParser: the app runs in browsers, but tests run in Node. Write a small tolerant scanner, guarded against unclosed tags and with a row cap.
- `spreadsheetml.js` exports `readSpreadsheetMl(text)` → `{ ok, rows }`. It uses `parseXml` from xml.js and reads the first Worksheet/Table/Row/Cell/Data, honouring ss:Index (skipped cells). Data of ss:Type DateTime becomes 'YYYY-MM-DD'.
- Route both in `readStatementFile` as kind 'table' with format 'html' / 'spreadsheetml'. Add both to FORMATS (types.js is NOT in allowed paths, so keep the format strings local to import.js; planner: confirm FORMATS is not validated anywhere).
- Tests (made-up data):
  - an HTML statement with a preamble table and a transactions table;
  - entities (&nbsp;, &amp;, &#257;);
  - <br> inside a cell;
  - colspan;
  - a SpreadsheetML workbook with ss:Index gaps and a DateTime cell;
  - detection of both;
  - a broken HTML file gives `{ ok: false }` and never throws.
