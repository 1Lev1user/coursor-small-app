## Goal
Release 3.1.0: raise the version pair, so installed apps get the Update bar. The data format stays at schema 3, so going back to 3.0 stays safe.

## Acceptance
- `node -e "process.exit(require('./package.json').version === '3.1.0' ? 0 : 1)"` exits 0
- `node --test test/serviceWorker.test.js` exits 0
- `npm run check:kit` exits 0
- Manual (owner): after publishing, the installed 3.0 app shows the Update bar and keeps all data
- `npm test` exits 0

## Do not touch
- existing test files
- src/
- SCHEMA_VERSION
- Limit for `package.json`: version only.
- Limit for `sw.js`: VERSION only.

## Notes
Use `npm version 3.1.0 --no-git-tag-version` (scripts/sync-version.mjs copies the version into sw.js).

Publishing is done by the orchestrator after this card merges, under the owner's go of 2026-10-17 ("3.1.0 to the site"):
- one fast-forward commit "Release 3.1.0" on v1, from scripts/ship-files.txt;
- the GitHub Release itself is created by the owner (the cloud session cannot create releases).
