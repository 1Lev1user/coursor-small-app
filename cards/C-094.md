## Goal
When the person ticks Remember in the Categorise step, the offered rule keyword names the shop. Since C-089 a Citadele transfer to "TELE2 SIA" offers the keyword "SIA", and a rule "SIA" would match every company. Five Bolt rows ("BOLT.EUR2610011807 Tallinn") offer an empty keyword, so Remember does nothing unless the person types one. After this card those rows offer "TELE2" and "BOLT.EUR".

## Notes
Code at 0bd76c3: `extractPattern` (core.js ~222) drops every token that contains a digit (`.filter((token) => token !== '' && !/\d/.test(token))`). That removes "TELE2" (so "TELE2 SIA" leaves only the legal form "SIA", which LEGAL_FORMS then cannot skip because it is the only token) and "BOLT.EUR2610011807" (so only the place "TALLINN" is left, which TRAILING_PLACES removes).
Fix: a token with letters and digits is kept after removing a trailing run of 4 or more digits, if at least 2 letters remain ("TELE2" stays "TELE2", "BOLT.EUR2610011807" becomes "BOLT.EUR", "HESBURGER" unchanged). A token that is all digits, or a token whose letters are fewer than 2 after the strip, is still dropped. A legal form left as the only token is never returned as a keyword: return '' instead.
Every existing case in importCore.test.js:81-89 must give the same result ('RIMI', 'MAXIMA', 'CIRCLE K', 'PAYPAL SPOTIFY' twice, 'LIDL', 'WOLT', '').
Tests (new file): 'TELE2 SIA' → 'TELE2'; 'BOLT.EUR2610011807 Tallinn' → 'BOLT.EUR'; 'BOLT.EU/R/2610061652 Tallinn' → 'BOLT.EU'; 'SIA' alone → ''; 'HESBURGER 43019 Riga' → 'HESBURGER'; 'Revolut**6588* Dublin' → 'REVOLUT'; 'RIMI SHM ORIGO (RIGA) RIGA' → 'RIMI'.
