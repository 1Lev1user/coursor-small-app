## Goal
The column guesser knows a short keyword list. Open sources now give the real headers of the most used banks in the region and of the main neobanks (research/3.1/bank-shapes.md, READ). After this card each of these headers is guessed correctly without manual mapping:
- the date, amount, direction, description, payee and reference columns;
- the repeated title and header lines of SEB multi-account files, which are skipped as summary rows.

## Notes
Also (from C-110): `splitBankDetails` returns an optional `original: { cents, currency }` for Swedbank and SEB foreign card payments. In `rowsToStatement`, when the row has no currency column or its currency is EUR, and `split.original` exists, pass `currency: original.currency` and `originalAmountCents: original.cents` with `amountCents` = the EUR amount of the row. The row then shows the original currency and keeps the EUR amount charged. Add a test.

Headers (READ, from research/3.1/bank-shapes.md):
- **Revolut:** `Type,Product,Started Date,Completed Date,Description,Amount,Fee,Currency,State,Balance`.
  - Date = Started Date (the payment time); Completed Date is empty for pending rows.
  - Amount signed.
- **Swedbank LV:** `Klienta konts;Ieraksta tips;Datums;Saņēmējs/Maksātājs;Informācija saņēmējam;Summa;Valūta;Debets/Kredīts;Arhīva kods;Maksājuma veids;Refernces numurs;Dokumenta numurs`.
  - Direction D/K. bankRef = Arhīva kods: NOT unique, because commission rows reuse it. C-068's text check keeps them apart; test it.
- **Swedbank EE:** `Reatüüp, Kuupäev, Saaja/Maksja, Selgitus, Summa, Valuuta, Deebet/Kreedit, Arhiveerimistunnus, Tehingu tüüp`.
- **SEB LT:** `"DOK NR.";"DATA";"VALIUTA";"SUMA";"MOKĖTOJO ARBA GAVĖJO PAVADINIMAS";"MOKĖTOJO ARBA GAVĖJO IDENTIFIKACINIS KODAS";"SĄSKAITA";"KREDITO ĮSTAIGOS PAVADINIMAS";"KREDITO ĮSTAIGOS SWIFT KODAS";"MOKĖJIMO PASKIRTIS";"TRANSAKCIJOS KODAS";"DOKUMENTO DATA";"TRANSAKCIJOS TIPAS";"NUORODA";"DEBETAS/KREDITAS";"SUMA SĄSKAITOS VALIUTA";"SĄSKAITOS NR";"SĄSKAITOS VALIUTA";`
  - There is a title line before it, and title plus header repeat per account.
  - A trailing `;` gives an empty last field.
  - Direction D/C. bankRef = TRANSAKCIJOS KODAS. Date = DATA, not DOKUMENTO DATA.
- **LHV:** `"Kliendi konto","Kuupäev","Saaja/maksja konto","Saaja/maksja nimi","Deebet/Kreedit (D/C)","Summa","Arhiveerimistunnus","Selgitus","Valuuta","Isikukood või registrikood","Kande viide"`.
  - English variant: `Customer account no, Date, Sender/receiver account, Sender/receiver name, Debit/Credit (D/C), Amount, Archiving code, Description, Currency, Personal code or register code, Transaction reference`.
  - Has a BOM. The sign of Summa is inconsistent, so the direction comes from D/C and the magnitude is abs(Summa).
- **Wise (23 columns):** `"TransferWise ID",Date,"Date Time",Amount,Currency,Description,"Payment Reference","Running Balance","Exchange From","Exchange To","Exchange Rate","Payer Name","Payee Name","Payee Account Number",Merchant,"Card Last Four Digits","Card Holder Full Name",Attachment,Note,"Total fees","Exchange To Amount","Transaction Type","Transaction Details Type"`.
  - Dates `DD-MM-YYYY`. Amount signed, with the fee already included.
  - bankRef = TransferWise ID. Never take Running Balance as the amount, and never take Total fees as a fee column.
- **N26:** `"Booking Date","Value Date","Partner Name","Partner Iban","Type","Payment Reference","Account Name","Amount (EUR)","Original Amount","Original Currency","Exchange Rate"`.
  - Amount = Amount (EUR). Original Amount/Currency is the foreign amount.

Tests: one per header above, with 3-4 made-up rows each in the documented separators and number formats. Assert the guessed columns, the direction and amount of each row, and that money in/out match. Also: SEB's repeated title and header lines are skipped. A Swedbank KOM commission row with the same Arhīva kods as the payment is not a duplicate of it (`findDuplicates`).
