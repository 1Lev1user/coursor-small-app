## Goal
A subscription row in a bank import is never matched silently: the import asks "Is this the Spotify subscription?" and the owner answers Yes or No; Yes marks the charge as the subscription's payment for that month, so its reminder stops. In the same way a money-in row close to a regular income's payday asks "Is this the <income name>?"; Yes ties the imported income to that source, so the payday reminder for that month closes. The "Subscription due" screen also offers Later and Skip this month.
